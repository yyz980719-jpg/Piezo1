# Data Availability

The study reuses publicly available transcriptomic datasets from NCBI Gene
Expression Omnibus under accessions GSE51588, GSE55235, GSE82107, GSE46750,
GSE104782, GSE57218 and GSE152805. The exact filenames, source identifiers,
expected byte sizes and SHA-256 checksums used by the analysis are listed in
`data/input_manifest.tsv`. Whole-blood cis-eQTL summary statistics were obtained
from eQTLGen Phase I, osteoarthritis outcome summary statistics from FinnGen
release 12, and the cross-resource exposure-scale comparison used GTEx v8 Whole
Blood data. These third-party data remain subject to their source resources'
access and reuse terms and are not redistributed in this software archive.

All original analysis code, frozen derived statistical tables, figure source
data, published figure images and reproducibility metadata are included in this
release. The permanent DOI sentence must be added after Zenodo or an equivalent
repository assigns the identifier.
