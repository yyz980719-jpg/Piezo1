# Exploratory historical analyses

These scripts and frozen outputs are retained for transparency because the
supplement describes immune, transcription-factor, motif, PROGENy, TWAS,
fine-mapping and druggability analyses as hypothesis-generating. They are not
part of the authoritative final inferential pipeline or its automatic `all`
stage. Some scripts depend on external APIs, PLINK resources, licensed data, or
historical local paths; consult the input manifest and script headers before
rerunning them. No result from this folder strengthens the central causal claim.
